## Funkin' MINECRAFT
 <img align="left" src="https://repository-images.githubusercontent.com/1005875821/85bc695e-151a-4b54-ac2c-204758292a0c" width="40%"> I'm developing Funkin' MINECRAFT. It's a rythm-based platform fighter where you sing, fight, mine, and craft to thwart your foes! Inspired by the strenghts of Friday Night Funkin' and MINECRAFT, gameplay is heavily data-driven with built-in tools for creating custom storylines, characters, songs, and terrain. 
 
It also has a website! [Funkin' MINECRAFT on GitHub Pages](https://go-miles.github.io/Funkin-MINECRAFT)

You can read about the game, see the latest updates, gloss over recent commits, and play nightly builds thanks to GitHub's CI services.
